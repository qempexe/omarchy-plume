# Code of conduct

Plume follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, keep criticism about the work and
not the person, and leave out harassment of any kind. Issues, pull requests and
discussions that don't keep to this are closed.

To report something, open an issue or contact the maintainer through
[GitHub](https://github.com/qempexe).
